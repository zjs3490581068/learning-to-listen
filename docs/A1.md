# A1：真实系统分层的五折复现

## 定义与论文关系

A1 将冻结的 MuQ 音频表示经可训练注意力池化送入两个独立 MLP，预测 MI（Musical Impression）和 TA（Textual Alignment）。
本实现沿用已完成实验的训练方法，修复上游数据协议中的伪系统分层及评估入口问题。
它不是论文所有消融、基线或全部数据协议的逐项复现；没有运行 FAD、SongEval 或其他编码器。

## 数据协议

- 只使用官方 train：1,923 条、31 个真实 TTM 生成系统，不合并 validation/test。
- 从 `audiomos2025-track1-S002_P055.wav` 提取 `S002`；严格核对官方原始文件名、唯一性与 MI/TA 标注。
- 不存在 `index % 31` 回退。缺失或非法系统 ID 直接失败。
- `StratifiedKFold(5, shuffle=True, random_state=42)`，分层变量为真实系统 ID。
- 各折验证数量：385、385、385、384、384；每折覆盖全部 31 系统，同一系统在不同验证折的数量差不超过 1。
- 这是系统分层，不是系统隔离：同一生成系统可以同时出现在训练和验证中。
- 每条样本保留整数 `clip_id`、原始 `audio_filename` 和字符串 `model_id`；预测保持加载顺序。
- 清单保存样本、标签、划分及逐音频 SHA-256，训练、预测、评估共用；HF 缓存位置不作为数据身份，替换音频内容仍会失败。

每折验证集同时用于早停、选模和最终评估，不是独立最终测试。没有额外嵌套验证。
1,923 条折外预测完整覆盖 train，但不能因为名为折外预测就忽略选模使用了验证集。

## 网络与训练参数

输入是 24 kHz 单声道 10 秒，MuQ 输出 1,024 维时序特征。
训练随机裁剪，验证中心裁剪，不足 10 秒末尾补零；保留原预处理，不缓存特征。

| 模块 | 结构 | 可训练参数 |
|---|---|---:|
| MuQ | 基础预训练编码器，参数冻结 | 0 |
| 注意力池化 | 1024→128→1，Tanh，时间维 softmax | 131,329 |
| MI MLP | 1024→256→1，GELU，dropout=0.1 | 262,657 |
| TA MLP | 同结构，独立权重 | 262,657 |
| 合计 | 池化及两个头 | 656,643 |

**参数冻结不等于始终 eval。** 原 A1 训练模式会更新编码器 BatchNorm 运行统计；冻结参数无梯度。
历史 fold0 审计中 462 个编码器参数张量不变、54 个缓冲张量改变。因此不能将训练替换成一次静态特征提取。
推理统一 eval。池化和头随机初始化，不从作者训练后的 A1 开始。

| 配置 | 设置 |
|---|---|
| 随机种子 | `42 + fold` |
| 目标 | MI MSE + TA MSE，等权 |
| 优化器 | AdamW，lr=0.001，weight decay=0.01 |
| batch / 精度 | 16 / CUDA bf16 |
| 最大轮次 / patience | 30 / 7 |
| 选模 | 验证 MI SRCC 最大 |
| 调度 | 500 步线性 warmup，起点 0.1 倍 lr；随后 cosine，最低 1e-7 |
| 梯度裁剪 | 全局范数 1.0 |
| DataLoader | 4 workers，pin memory；训练 shuffle/drop_last，验证不乱序/不丢尾批 |
| 不启用 | LoRA、对比损失、额外数据、校准、不确定性加权、梯度检查点、特征缓存 |

YAML 中保留某些共享模型/损失字段，仅用于模型兼容，不表示 A1 启用了这些功能。

## 运行与产物

```bash
python scripts/prepare_assets.py
python scripts/run_a1_true_ttm.py
# 显式并行，仍须先通过 fold0 验收
CUDA_VISIBLE_DEVICES=0,1,2,3 python scripts/run_a1_true_ttm.py --max-parallel 4
# 完整折复用，不是中断续训
python scripts/run_a1_true_ttm.py --resume
# 独立预测和评估
python generate_predictions.py --fold 0
python run_evaluation.py --config configs/A1_true_ttm.yaml --all-folds --bootstrap
```

默认输出 `outputs/A1_frozen_mlp_true_ttm/`。
每折有最佳完整模型、训练历史、原始最佳模型预测、评估结果和资源记录；根目录有固定划分、运行状态、汇总与学习曲线。
历史命名 `test_predictions.json` 实际是该折验证预测，不是官方 test。
按真实系统 ID 分别聚合预测和人工标签，计算样本级及系统级 SRCC/PCC/Kendall；各折执行 1,000 次 BCa bootstrap 的 95% 区间。
五折汇总使用均值和 `ddof=0` 标准差。置信区间不等同于跨折标准差。

先完成 fold0，再核对有限损失/指标、冻结编码器梯度、池化/头梯度、重载一致性及全部 385 条预测；失败不启动后续折。
发布版清单 `manifest_format=2` 增加逐音频摘要。旧私有清单不自动转换或绕过验证；短模型兼容性检查只确认权重结构与前向，不能代替数据清单迁移。
五折结束核对折外预测无重复、无遗漏。默认单卡，不会自动占满机器。
完整最佳检查点各含基础编码器，五折历史占用约 6.7 GB，不纳入源码仓库。

## 已完成的参考结果

以下来自整理前的固定实验；发布整理没有重新训练：

| 指标 | fold0 | 五折均值 ± 标准差 |
|---|---:|---:|
| MI 样本 SRCC | 0.822704 | 0.830650 ± 0.008580 |
| MI 样本 PCC | 0.817724 | 0.821366 ± 0.007836 |
| TA 样本 SRCC | 0.543243 | 0.589168 ± 0.029671 |
| TA 样本 PCC | 0.554571 | 0.592296 ± 0.024418 |

fold0 最佳检查点内部 epoch=22，即从 1 开始的第 23 轮，实际训练 30 轮、2,880 次更新。
历史训练约 772.2 秒、峰值分配约 3.253 GiB；这是特定共享服务器条件的观测，不是性能承诺。

原实验文档中固定的论文 v2 对照（2026-10-28 版本）为 MI 样本 SRCC 0.838±0.016、PCC 0.828±0.017，
TA 样本 SRCC 0.591±0.034、PCC 0.594±0.041。此处保留历史对照，不宣称逐协议一致，也不因未达数值而自动调参。
课堂页面只使用 fold0，不是五折模型集成；其 413 条官方 test 另按独立清单处理。
