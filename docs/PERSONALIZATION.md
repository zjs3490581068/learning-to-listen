# A3a：最后四层 LoRA 个人偏好评分器

## 定义与模型起点

本实验学习使用者人为指定的偏好标签，不是 MusicEval 客观质量评估的替代。
它是基于 A3a 架构与作者检查点的扩展，不是作者 A3a 主实验的重新训练复现。
作者完整 `model_state_dict.pt` 先严格加载，不使用缺失键容错。

已用检查点中原 LoRA 匹配到量化器 `out_proj`，在当前评分前向路径中没有被调用。
为兼容严格加载，保留该结构，但冻结且停用；不将它算作本次有效适配。
新增名为 `personal` 的适配器，只作用于实际 Conformer 第 9–12 层（零基索引 8–11）：

```text
.*conformer.layers.(8|9|10|11).self_attn.(linear_q|linear_k|linear_v|linear_out)
```

具体转义后的正则见配置；共 16 个注意力投影模块。r=16、alpha=32、dropout=0.1、bias=none，LoRA B 零初始化。
零增量初始化应不改变作者模型输出；该检查在训练更新前执行。

| 可训练模块 | 参数量 |
|---|---:|
| 新 LoRA | 524,288 |
| 原注意力池化 | 131,329 |
| 原 MI 五档预测头，1024→512→512→5 | 790,021 |
| 合计 | 1,445,638 |

池化和 MI 头继承作者权重，不重新随机初始化。其余参数及 BatchNorm 运行统计冻结；TA 头不接受偏好标签训练。
`preference_score = sum(softmax(MI_logits)[k] * (k+1))`，用 float32 计算五档期望。
范围自然在 1–5，不增加缩放、手动截分、校准或对比损失。

## 原实验数据与标签

十二首完整解码可用的 Ogg 每首 8 段，共 96 段，再从官方 MusicEval train 不放回抽 54 条，总计 150。
不读取歌手名、文件名或标签文本作为模型输入，只输入波形。

| 标签 | 歌曲/来源 | 训练 | 验证 |
|---|---|---:|---:|
| 5 | 小少焱：上下五千年、中渡桥、匹夫、唐宋八大家、天命 (那只猴子死后)、寒门贵子、少年游 (DJ版)、第六单元 | 48 | 16 |
| 3 | 九九八十一 | 6 | 2 |
| 2 | 丈夫歌、卧龙吟、有为歌 | 18 | 6 |
| 1 | 官方 MusicEval train | 48 | 6 |
| 合计 | 150 条，每首 6 训练/2 验证 | 120 | 30 |

歌名、匹配规则、标签、数量和展示顺序见 `configs/music.original.yaml`，不在模型代码中写死。
没有原始录音就不能逐样本重现原实验；同名的翻唱、混音、编码或时长不同，也可能改变切片及得分。
不分发原歌曲，也不将 MusicEval 的原人工 MOS 改写成 1；另存 `preference_target=1`，保留原 MI/TA 和系统 ID。

## 确定性切片

1. 完整解码，转为 24 kHz 单声道；根据完整源峰值确定必要衰减，所有同源片段共用，最高 -1 dBFS，不做响度归一化。
2. 用 100 ms 帧 RMS，静音阈值为 `max(-60 dBFS, 全曲帧能量 Q90 - 35 dB)`。
3. 候选为 1 秒起点网格上的 10 秒段，静音占比不超过 10%，整体 RMS 至少 -40 dBFS。
4. 通常去掉首 20 秒及尾 10 秒；短于 110 秒的录音首尾各去 10 秒，原实验对应《丈夫歌》。
5. 动态规划选满互不重叠的 8 段，先减少静音，再接近均匀时间锚点，平局选更早位置。不能选满就报错，不自动放宽。
6. seed=42，由源文件名派生稳定随机流，每首 8 段固定随机分成 6/2；MusicEval 固定排序、随机抽取和中心裁剪。
7. 输出 PCM-24 WAV，重新读取核对；训练与评分均读取这些最终文件，保存源和切片摘要、时间、能量与划分。

**没有使用人声检测，也没有自动完成主观听审。** 能量规则能排除长静音，不能保证排除纯伴奏。
歌曲边缘只是一种启发式规则，教师应试听时间清单确认实际内容。

## 展示隔离

| 固定歌曲 | 左闭右开区间 | 偏好目标 | 预设展示区间 |
|---|---|---:|---|
| 第六单元 | 90–100 秒 | 5 | [4,5] |
| 上下五千年 | 247–257 秒 | 5 | [4,5] |
| 九九八十一 | 224–234 秒 | 3 | [2.5,3.5] |
| 卧龙吟 | 107–117 秒 | 2 | [1.5,2.5] |
| MusicEval | 官方 test 预先随机固定的合格音频中心 10 秒 | 1 | [1,1.5] |

四段个人展示区间与任何训练/验证切片不得重叠，不额外加缓冲。
MusicEval 展示例不依据预测分数挑选或替换；历史为 `S016_P016`，中心 10–20 秒，原人工 MI=4.2、TA=4.8。
目标区间只在训练与选模结束后检查，不用于选轮次、校准或调参。
同曲其他片段参与训练，因此只能称为同曲未见区间展示，不能称为未见歌曲泛化。

## 训练设置

| 项目 | 设置 |
|---|---|
| seed | 42 |
| 损失 | Gaussian ordinal CE，5 bins，sigma=0.5 |
| 优化器 | AdamW，weight decay=0.01 |
| 学习率 | LoRA/池化 1e-4，MI 头 1e-3 |
| batch / 精度 | 16 / CUDA bf16 |
| 更新 | 原实验每轮 8 次，最多 30 轮 |
| 调度 | 24 步线性 warmup，再 cosine；最低 1e-7 |
| 梯度裁剪 | 全局范数 1.0 |
| 选模 | 验证各标签宏平均 MAE 最低；再比较总体 MAE，仍平局取更早轮次 |
| patience | 7 |
| 不启用 | 类别重采样、额外对比目标、TA 偏好训练、展示集选模 |

冻结参数没有梯度，LoRA、池化、MI 头有有限梯度；BatchNorm 统计不变。
完整最佳模型与轻量权重均导出；轻量权重包含 LoRA、池化及 MI 头，必须结合同一作者起点重建，不是独立基础模型。
验证使用 `no_grad()`，避免 MuQ 旋转位置缓存经 `inference_mode()` 创建后不能参与训练反向的已知问题。
必须先把模型移到目标 GPU，再首次前向。

## 运行及自定义音乐

```bash
python scripts/audit_local_audio.py
python scripts/run_personalization.py --stage prepare
python scripts/run_personalization.py --stage train --gpu 0
python scripts/run_personalization.py --stage evaluate --gpu 0
python scripts/run_personalization.py --stage report
python scripts/verify_personalization.py --browser
```

`prepare/train/evaluate/report/all` 各阶段读取同一实验配置。原实验输出为 `outputs/A3a_personalized_last4_seed42/`。
`prepare` 核对已有清单，不静默换数据；`train` 拒绝覆盖已有模型。已有结果不能作为另一个配置反复训练的输出目录。

自定义时修改 `configs/music.custom.example.yaml` 中歌曲 pattern、偏好标签、保护区间等，再始终使用：

```bash
python scripts/run_personalization.py --config configs/A3a_custom.example.yaml --stage all
python scripts/verify_personalization.py --config configs/A3a_custom.example.yaml
```

每首应恰好匹配一个 Ogg，不能重复匹配文件；标签必须为整数 1–5；训练和验证均非空。
自定义协议为 `personalized_custom_last4_v1`，不得继续宣称是固定 150 条的原实验。
自定义每轮更新数随数据量计算，保持原学习率、24 步 warmup 和训练目标；验证宏平均遍历实际存在的标签。
展示顺序必须包含全部有保护区间的歌曲及一个 MusicEval test 例。

独立推理：

```bash
# 完整源先确定共享增益，再取指定区间；省略 start 则取中心，不足 10 秒报错
python scripts/predict_preference.py --audio data/personal_music/example.ogg --start-sec 90
# 已准备的 24k/mono/10s PCM-24 不再施加增益或裁剪
python scripts/predict_preference.py --audio outputs/A3a_personalized_last4_seed42/audio/demo/example.wav --prepared --lightweight
```

示例文件名需替换为本人清单实际生成的路径。不同 batch 的 bf16 可能有轻微数值差异；课堂表使用固定 batch=16 流程。
改存储位置不会改变新格式身份，但修改权重、清单或方法配置会拒载。旧私有检查点采用不同身份格式，不自动绕过验证迁移。

## 网页具体内容

“课堂试听”逐行显示固定歌曲、时间段、波形、播放器、WAV 下载。原实验五行依次为第六单元、上下五千年、九九八十一、卧龙吟、MusicEval。
评分默认隐藏；揭示后有作者 MI、个人偏好分、偏好目标、预设区间及区间内/外判断。
只播放一条音轨，切换页签自动暂停；本页面不是任意音频上传推理服务。

“验证与曲线”显示宏平均 MAE、总体 MAE、最佳轮次/实际轮次；曲线含训练/验证 CE、验证宏平均与总体 MAE、最佳轮次标线。
验证分布并列作者 MI 与个人模型，类别表列样本数、作者 MAE、个人 MAE 和个人平均分。
CSV 下载包含展示评分、全部预测、切片清单；实验记录说明标签语义、同曲训练关系、能量筛选和共享增益。
自定义实验的样本数、标签类别与展示数量从实际结果生成。
`index.html`、音频、图片、表格均相对引用，可直接离线打开；自动 `REPORT.md` 不覆盖仓库人工文档。

## 历史真实结果

整理前实验训练 28 轮、224 次更新，最佳为第 21 轮：

| 验证指标 | 作者 MI 对个人标签 | 微调模型 |
|---|---:|---:|
| 宏平均 MAE | 1.743028 | 0.149636 |
| 总体 MAE | 1.482639 | 0.129652 |
| RMSE | 1.671827 | 0.149376 |
| SRCC | 0.116519 | 0.912648 |

作者 MI 与个人标签语义不同，这不是证明作者质量模型差，只比较本次偏好匹配。

| 固定展示 | 作者 MI | 微调偏好分 |
|---|---:|---:|
| 第六单元 | 4.407804 | 4.874052 |
| 上下五千年 | 4.422968 | 4.883840 |
| 九九八十一 | 4.567097 | 3.064538 |
| 卧龙吟 | 4.256345 | 2.033983 |
| MusicEval | 4.221777 | 1.200985 |

五例达到预设区间，但这不是新运行保证。没有为达到目标改分、重选展示或进行自动调参。
零增量初始化、完整重载、轻量重建、最终 WAV 重读的历史最大差均为 0；不保证不同硬件依然逐位一致。
该数据规模小、标签与歌手/来源/风格高度相关，模型可能学习这些相关特征。
验证参与选模，无跨种子重复、独立未见歌曲评估或个人偏好置信区间，不应作此类泛化声明。
